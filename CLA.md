## 7. How to sign

Sign by posting a comment on the pull request that introduces your
Contribution, of which the body starts with:

```text

and I hereby sign the CLA.
```

The project's CLA workflow turns the `cla` status check green once the
signature comment is recorded. Subsequent contributions under the same GitHub
account are covered automatically — the workflow recognises prior signatures
on later pull requests by the same author.
